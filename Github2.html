Task 1:
For the first task in this lab I was required to take the work that I had produced last week from its repository on GitHub and make a new one for this lab. I did this by pulling the contents from GitHub onto my local repository, creating an "old assignment" and "new assignment" folder. I moved the contents in the cloned repository into the "old assignment" folder before copying it into the "new assignment" folder. Once I had done this, I pushed the folder into the new GitHub repository I had been provided.

Task 2:
For Task 2 I had to create a new workflow; the way I did this was by republishing my website in the new repository and changing the Pages setting from "Deploy from a Branch" to "GitHub Actions", which enabled the Actions tab to appear. From there I navigated to the Actions page, selected "Create New Workflow" and was brought to the workflow configuration page where I changed the workflow name from main.yml to deployment.yaml. I needed this workflow because this is where I would put the YAML to help automate my website's deployments when an update is made to it.

Task 3:
The third task for the coursework required me to produce the YAML code for my website to allow me the opportunity to add metadata to my pages. YAML is used by GitHub Actions to define automated workflows and deployment instructions for the website. By creating this YAML file, it allowed GitHub Actions to automatically deploy the website whenever changes were uploaded to the repository.
