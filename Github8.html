Task 1

1)
Given the following:

Virtual address:
VPN – 4-bit VPN, 8-bit offset

Physical address:
3-bit PPN, 8-bit offset

Determine the number of virtual pages and bytes per page.

The 4-bit VPN determines the number of virtual pages:
2^4 = 16

The 8-bit offset determines the number of bytes per page:
2^8 = 256

Therefore:
Number of virtual pages = 16
Bytes per page = 256 bytes

2)
Virtual address = 0x2C8

To find the VPN, the first hexadecimal digit is used because each hexadecimal digit represents 4 bits.

VPN = 0x2
Offset = 0xC8

The page map gives the following values:

VPN: 2
D: 0
R: 1
PPN: 4

Therefore:
PPN = 4
Resident bit (R) = 1
Dirty bit (D) = 0

Final answer:
VPN = 0x2
Offset = 0xC8
PPN = 0x4

Task 2

The bottom of main memory is 32KB.

It is divided into 8 page frames, each being 4KB in size.

4KB = 4096 bytes

Since memory addresses start at 0, the highest address in each frame is calculated using:

Starting Address + 4095

Value of all frames:

Frame 0 → 0 + 4095 = 4095 → D
Frame 1 → 4096 + 4095 = 8191
Frame 2 → 8192 + 4095 = 12,287
Frame 3 → 12,288 + 4095 = 16,383 → C
Frame 4 → 16,384 + 4095 = 20,479
Frame 5 → 20,480 + 4095 = 24,575 → B
Frame 6 → 24,576 + 4095 = 28,671
Frame 7 → 28,672 + 4095 = 32,767 → A

Final answers:

A = 32,767
B = 24,575
C = 16,383
D = 4095

Task 3

Before solving the problem, the 32-bit virtual address must be split into the page number and offset.

The first 20 bits represent the page:
00000000000000000011

The final 12 bits represent the offset:
000010110111

3a)
Find the Virtual Page Number:

VPN bits = 11

This corresponds to page number 3.

Therefore:
Virtual Page Number = 3

3b)
To find the page frame value, I looked in the table for Virtual Page Number 3.

The table showed:

Virtual Page: 3
Present Bit: 1
Page Frame: 011

Binary page frame value = 011

Converting binary to denary:

0 × 2^2 = 0
1 × 2^1 = 2
1 × 2^0 = 1

0 + 2 + 1 = 3

Therefore:
Binary Page Frame Value = 011
Denary Page Frame Value = 3
